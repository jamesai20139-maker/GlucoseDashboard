# 血糖資料表填寫說明

本檔案教你如何填寫 Google Sheet（或匯出的 CSV），讓血糖儀表板能正確讀取與分析。
請搭配同目錄的 `sample-sheet.csv` 範例檔一起看。

## 一、檔案格式

儀表板透過 Google Sheet 的「公開匯出 CSV」連結讀取資料，所以你的 Google Sheet 內容
**必須符合下列 5 個欄位，且順序不可改變**。第一列一定是欄位標題，從第二列開始才是資料。

| 欄位順序 | 欄位名稱           | 必填 | 說明                                   |
| -------- | ------------------ | ---- | -------------------------------------- |
| 1        | `血糖量測日期時間` | 是   | 量測的日期與時間，格式見下方說明       |
| 2        | `事件`             | 是   | 量測時機，只能填內建事件或自訂事件名稱 |
| 3        | `量測血糖值(mg/dl)` | 是   | 血糖數值，整數，範圍 20–600            |
| 4        | `備註1`            | 否   | 自由文字備註                           |
| 5        | `備註2`            | 否   | 自由文字備註                           |

> ⚠️ **欄位名稱與順序是固定契約，不可更改**。若標題列與上表不符，儀表板會直接停止
> 分析並回報「欄位標題不符合規定」。多加欄、少欄、改名、調換順序都會造成錯誤。

## 二、欄位填寫規則

### 1. 血糖量測日期時間（必填）

支援下列日期格式，**日期與時間之間以一個空白分隔**：

- `2026/08/10 06:30`（推薦，最不容易出錯）
- `2026-08-10 06:30`
- `2026/8/10 06:30`（可不補零）
- `2026/8/7 上午 7:11:00`（Google Sheets zh-TW 匯出的本地化格式，含「上午/下午」、可帶秒）
- 帶秒的純數字格式亦可：`2026/8/7 14:30:00`

不支援的常見錯誤寫法：

- `2026/08/10`（只有日期沒有時間）
- `08/10 06:30`（缺年份）
- `2026年8月10日 06:30`（中文單位）
- `下午 0:00` / `下午 13:00`（12 小時制時數須在 1–12；24 小時制時數須 ≤ 23）

> 💡 若你的 Google Sheet 顯示成「2026/8/7 上午 7:11:00」這類本地化格式，不用特別改，
> 儀表板可以直接解析。

### 2. 事件（必填）

內建事件**只能填下列六個中文名稱之一**，需完全相符（不可多空格、不可用簡體）：

| 事件名稱 | 情境             |
| -------- | ---------------- |
| `空腹血糖` | 起床空腹時量測   |
| `午餐前`   | 午餐前量測       |
| `午餐後`   | 午餐後量測（通常餐後 2 小時） |
| `晚餐前`   | 晚餐前量測       |
| `晚餐後`   | 晚餐後量測（通常餐後 2 小時） |
| `睡前`     | 睡前量測         |

除了內建事件，你也可以透過 Google Sheet 的**兩個設定工作表**新增**自訂事件**並設定
每個事件的血糖標準值範圍（儀表板不再提供介面新增事件，一律從 Sheet 即時讀取）：

1. **「事件關鍵字設定」工作表**（單欄）：第一列為標題 `事件關鍵字`，第二列起每列填一個
   自訂事件名稱（例如 `運動後`）。與內建六個事件同名者會自動略過。
2. **「血糖標準值設定」工作表**（三欄）：第一列為標題 `事件,血糖下限,血糖上限`，
   第二列起每列填一個事件與其標準值範圍（上下限皆須為 20–600 的整數，且下限 < 上限）。
   **必須包含全部六個內建事件**，自訂事件可於其後追加；未在此表列出的自訂事件會
   退回預設標準 `70–139`。

> ⚠️ 這兩個工作表的名稱預設為「事件關鍵字設定」「血糖標準值設定」（可在儀表板設定中
> 指定自訂名稱）。若工作表缺失、空白或標題不符，儀表板會停止分析並回報是哪一個
> 工作表的問題。**未在「事件關鍵字設定」中列出的事件名稱會被當成「未知事件」，
> 該列不會參與統計。**

### 3. 量測血糖值(mg/dl)（必填）

- 必須是**整數**（不要寫小數點、單位或文字，例如 `92` 正確，`92 mg/dL` 錯誤）。
- 有效範圍 **20–600**，超出範圍或無法解析為整數的值會被略過並回報問題。
- 建議直接填入血糖機顯示的數字。

### 4. 備註1 / 備註2（選填）

- 可留空。
- 若備註內容包含**逗號**或**引號**，請用雙引號把整段備註包起來，內部的引號改用兩個雙引號。
  - 正確範例：`"早餐,2顆藥"` → 會完整視為備註1，不會被逗號拆成兩欄。
  - 錯誤範例：`早餐,2顆藥` → 逗號後面會被誤當成備註2。

## 三、無效資料的處理方式

儀表板採「**略過無效列、保留有效列**」的策略，不會修改你的原始資料：

| 情況                                   | 結果                                       |
| -------------------------------------- | ------------------------------------------ |
| 缺日期 / 事件 / 血糖值其中之一         | 該列略過，並在資料品質清單提示             |
| 日期格式無法解析                       | 該列略過，標記為錯誤                       |
| 事件不是內建事件，也未列於「事件關鍵字設定」工作表 | 該列略過，標記為未知事件                   |
| 血糖值不是整數或不在 20–600            | 該列略過，標記為錯誤                       |
| 備註欄格式錯誤（例如未加引號含逗號）   | 可能導致欄位錯位，建議參照上方規則補上引號 |

> 💡 即使某幾列出錯，其餘有效資料仍會正常顯示與統計。你可在儀表板的「診斷 / 資料品質」
> 頁面看到每一列的問題與列號，再回到 Google Sheet 修正即可。

## 四、設定注意事項

1. **Google Sheet 需設為公開可讀**（任何人持有連結皆可檢視），儀表板才能透過公開
   匯出連結讀取，不需要登入或 OAuth 授權。
2. 在儀表板設定中填入 Google Sheet 連結或 ID（可接受完整網址，會自動擷取 id/gid）。
3. 資料**每次重新整理儀表板時都會重新讀取**，不會另外存一份資料庫，所以你只要改完
   Google Sheet 存檔，重新整理頁面就會看到最新結果。
4. 請勿在 Sheet 中插入空白列或多層表頭；第一列必須是欄位標題，第二列起每一列就是一筆量測。
5. 自訂事件與血糖標準值一律從 Google Sheet 的「事件關鍵字設定」「血糖標準值設定」
   兩個工作表即時讀取（不在儀表板設定介面新增）。兩個工作表的標題與格式請見上方
   「### 2. 事件」段落的說明；任一工作表缺失、空白或標題不符都會中斷分析。

## 五、關於 sample-sheet.csv 範例檔

`sample-sheet.csv` 是一份可直接使用的範例資料檔，內含橫跨兩天的 12 筆量測，
涵蓋全部六個內建事件，並示範了「備註含逗號需加雙引號」的寫法。

- **用 Excel 開啟看到亂碼屬正常**：為了讓 Excel 正確顯示中文，範例檔已加上 UTF-8 BOM。
  這不影響內容，直接全選複製、貼進 Google Sheet 即可（Sheet 會自動處理編碼）。
- **貼入 Google Sheet 的步驟**：
  1. 在 Google Sheet 新增一個試算表，第一列依序填入五個欄位標題：
     `血糖量測日期時間`、`事件`、`量測血糖值(mg/dl)`、`備註1`、`備註2`。
  2. 開啟 `sample-sheet.csv`（Excel 或文字編輯器皆可），複製第二列起的資料。
  3. 在 Google Sheet 的 **A2** 儲存格貼上，再依實際量測時間與數值修改即可開始使用。
- 若要用「檔案 → 匯入」的方式上傳 CSV，選擇「取代目前工作表」、偵測分隔符號為「逗號」即可。

> ⚠️ 範例檔的 UTF-8 BOM 僅是為了方便用 Excel 預覽，**不需要也不應該**手動在 Google Sheet
> 裡加任何 BOM 或特殊字元；Sheet 本身的編碼會自動處理。
